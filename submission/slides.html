Architecture & Distillation Pipeline

Heavy model distillation done offline. Production serving is a lightweight CPU lookup.

Offline Pipeline (GPU Training)

  • Synthetic Augmentation: Qwen2.5-7B generated 17,490 questions for 1,498 zero-shot misconceptions.
  • Retriever Fine-Tuning: BGE-small (33M) with hard-negative mining.
  • Teacher & Distillation: 7B LoRA teacher → distilled into 22M MiniLM.
  • Explanation Precompute: Pre-stored Socratic ladders for all 2,587 misconceptions.

Production Serving (1 CPU Core)

  • Bi-Encoder INT8 ONNX: 2,587 × 384 matrix NumPy matmul (3.9 MB).
  • Cross-Encoder INT8 ONNX: Reranks top-25 down to top-1.
  • Primary-Key DB Lookup: SQLite fetches instant pedagogical hints.
  • FastAPI: Under 150 MB RAM, sub-400ms latency.

Key Architectural Finding: Offline precomputation of pedagogical hints over a bounded 2,587-class taxonomy eliminates live LLM latency, enabling sub-400ms local CPU inference at a fraction of cloud API costs.

Failure Analysis & Next Steps

Current Failure Modes

1. Missing Visuals: Questions requiring unrendered diagrams (e.g. tick marks on number lines).

2. Ambiguous Distractors: Two distinct misconceptions consistent with one student choice.

Next Iteration
