04 / 06

Two-Stage Retrieval & Distillation Pipeline

Heavy frontier models run offline once for synthetic augmentation and teacher supervision. Serving is distilled into a compact 22M INT8 ONNX model running on commodity CPU.

Offline Training (GPU Infrastructure)

Training & Distillation

  • Synthetic Augmentation: Qwen2.5-7B generated 17,490 diagnostic question pairs covering 1,498 zero-shot taxonomy classes (58% of taxonomy).
  • Retriever Training: BGE-small (33M) contrastive fine-tuning with hard-negative mining; real pairs oversampled 6× to preserve seen performance.
  • Teacher Model: Qwen2.5-7B + LoRA listwise cross-encoder reranker trained over top-25 candidate pools.
  • Knowledge Distillation: Teacher soft scores distilled into a 22M MiniLM-L6 cross-encoder via KL divergence loss.
  • Explanation Caching: Socratic hint ladders for all 2,587 misconceptions precomputed and indexed into SQLite.

Production Runtime (1 CPU Core)

Deterministic Serving Path

1. Bi-Encoder Embedding (INT8 ONNX) ~15 ms

Encodes question and student response into 384-d normalized vector.

2. NumPy Matrix Multiplication <1 ms

Evaluates query vector against 2,587 × 384 index (3.97 MB) to select top-25.

3. Distilled Cross-Encoder (INT8 ONNX) ~360 ms

Reranks top-25 candidate misconceptions down to top-1 prediction.

4. SQLite Primary-Key Lookup <1 ms

Fetches Socratic hint progression and educator probes from indexed storage.

Bounded taxonomy ensures zero cloud API dependence, sub-400ms latency, and 100% uptime.

Failure Analysis & Product Roadmap

A credible machine learning submission analyzes where the system struggles. We cataloged held-out failure cases to drive our next architectural iteration.

Observed Failure Modes

1. Diagram & Visual Dependency

Questions requiring unrendered geometric diagrams or number-line intervals cause text-only embeddings to misclassify procedural errors.

2. Overlapping Distractor Misconceptions

Certain incorrect options are mathematically consistent with two distinct misconception labels. Forcing a greedy top-1 prediction leads to arbitrary selection.

Development Roadmap

1. Interactive Disambiguation Dialogues

When top candidates have overlapping confidence scores, prompt the student with one diagnostic clarifying question instead of guessing.

2. Curriculum-Aware Adaptive Sequencing

Feed live misconception state directly into knowledge-tracing engines to dynamically build customized problem progression paths.

3. Cross-Discipline Taxonomy Scaling

Expand the bounded retrieval architecture to physics problem-solving, grammar rules, and introductory Python programming.
